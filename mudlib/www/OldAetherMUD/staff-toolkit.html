Ambassador file tools and high-mortal commands. Granted to every staff role (apprentice, rp_wiz, domain_wiz, creator/immortal, arch/head arch) in addition to role-specific tools.

High-mortal commands

cmds/hm: all staff roles, and mortals above level 19.

CommandWhat it does
markMark room as teleport anchor.
teleportTo marked/start location, or same-class player.
startSet login start to current room.
titlePost-name title. No-op for staff (use setenv TITLE).
messageRoom entry/exit messages.
reviewShow message strings and title.
createConjure weapon, armor, or bag.
cloakRogue stealth toggle.
marry / divorceWed or divorce two players.

Conversion gap: most of cmds/hm is unconverted Nightmare III. create and cloak check old skill percentages. marry/divorce require admin or legacy class monk (never set by Rifts chargen); in practice admin-only.

Legacy skill commands

Most of cmds/skills/ (~70 files, e.g. fireball, backstab, heal) still gates on NM3 classes (mage, cleric, monk, kataan, fighter, rogue). Live in the search path but inert for Rifts characters. Rifts-converted: limbs, replace (Medical Doctor), lockpick (Pick Locks). Spells/psionics: cast / psi (Commands).
