Character creation

  • Account login, then character select. Max 5 characters per non-staff account.
  • Room: /domains/Praxis/setter.c. No guide NPC; the room drives every prompt itself.
  • Pool: 62 races, 66 classes, 158 skills (class/RCC package at finish; more skills via RP-Wiz in play).
  • Answers are plain words/names (no command verb).

Login

  1. Account name
  2. Password
  3. Character select: number, or new
  4. New character: gender (male / female), optional display name

Chargen steps

  1. Zone: americas, atlantis, or europe
  2. Attributes: roll, then accept or reroll (up to 4 rerolls). Race locked until accept.
  3. Race: list, then name (e.g. human)
  4. Alignment: name (e.g. scrupulous)
  5. Class: list, then name (e.g. headhunter), or none
  6. Finish: package skills, languages, gear, teleport to zone start. No elective/secondary skill picking at chargen.
