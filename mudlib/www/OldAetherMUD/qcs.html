Quick Creation System

Staff of Creation verbs for rooms, NPCs, weapons, and armor. Work in your realm sandbox first.

Core verbs

create room <dir> <filename>
create npc|weapon|armor <filename>
modify here|<filename> <property> <value>
add exit <dir> <path>
add <npcfile> to here
add <npcfile> to <roomfile>
delete <object>
about <filename|here>
more <filename|here>
clone <filename>
purge <object>

Properties

Room:   short, long, light, indoors
NPC:    name, short, long, level, hp, race, occ, align, mdc
Weapon: name, short, long, wc, type, damage (NdN), mdc (0/1)
Armor:  name, short, long, ac, ar, sdc, mdc, slot

HP, SDC, MDC

  • SDC being (mdc 0, default): HP via hp / rifts_hp; optional SDC buffer drains first. Unconscious at 0 HP; dead at -10 HP. QCS starts with HP only (SDC 0). Add buffer by hand: set_stats("SDC", n); and set_stats("max_SDC", n);.
  • MDC being (mdc N, N > 0): single MDC pool. Only MDC weapons damage the pool.
  • Worn armor drains first (armor MDC/SDC), then wearer pools.

Paths

/realms/<you>/area/room/
/realms/<you>/area/npc/
/realms/<you>/area/weap/
/realms/<you>/area/armor/

Example session

Wizard name in paths: coder. Start from workroom with Staff of Creation in inventory.

Room

create room north practice_room
QCS: wrote and updated /realms/coder/area/room/practice_room.c
QCS: wrote and updated /realms/coder/workroom.c
QCS: room created. Exit 'north' wired to /realms/coder/area/room/practice_room
north
modify here short A practice chamber
modify here long A bare chamber for learning the builder.
add exit east /realms/coder/area/room/armory
about here
/* /realms/coder/area/room/practice_room.c */
/* QCS room by Coder */

#include <std.h>
#include <rooms.h>

inherit ROOM;

void create() {
    ::create();
    set_property("light", 2);
    set_property("indoors", 0);
    set_short("A practice chamber");
    set_long("A bare chamber for learning the builder.");
    add_exit("south", "/realms/coder/workroom");
    add_exit("east", "/realms/coder/area/room/armory");
}

NPC

Filename becomes the id (set_id(({ "bandit" }))). No separate QCS verb for ids; hand-edit for extras.

create npc bandit
modify bandit name bandit
modify bandit short a lean bandit
modify bandit long A lean bandit in scavenged armor watches the exits.
modify bandit race human
modify bandit level 5
about bandit
/* /realms/coder/area/npc/bandit.c */
/* QCS NPC by Coder */

#include <std.h>

inherit "/std/rifts_npc";

void create() {
    ::create();
    set_name("bandit");
    set_npc_name("Bandit");
    set_id( ({ "bandit" }) );
    set_short("a lean bandit");
    set_long("A lean bandit in scavenged armor watches the exits.");
    set_level(5);
    set_max_hp(20);
    set_hp(20);
    set_stats("rifts_hp", 20);
    set_aggressive(0);
    set_moving(0);
    set_gender("neuter");
    set_race("human");
    setenv("rifts_occ", "mercenary");
    set_alignment(0);
    set_body_type("human");
    set_property("mdc_creature", 0);
    set_stats("MDC", 0);
    set_stats("max_MDC", 0);
    set_default_response("The creature watches silently.");
}
  • This bandit is SDC: 20 HP, no SDC buffer. Add SDC with hand-edit as above.
  • modify bandit mdc 90 switches to a 90-MDC pool (no HP/SDC layering).

Weapon

create weapon vibro_knife
modify vibro_knife name vibro knife
modify vibro_knife short a vibro-knife
modify vibro_knife long A short blade that hums with ultrasonic vibration.
modify vibro_knife type blade
modify vibro_knife damage 2d6
modify vibro_knife mdc 1

damage writes damage_num, damage_sides, damage_string. mdc 1 clears the SDC weapon flag (multiple "wrote and updated" lines per command are normal).

about vibro_knife
/* /realms/coder/area/weap/vibro_knife.c */
/* QCS weapon by Coder */

#include <std.h>

inherit "/std/weapon";

void create() {
    ::create();
    set_name("vibro knife");
    set_id( ({ "vibro_knife", "weapon" }) );
    set_short("a vibro-knife");
    set_long("A short blade that hums with ultrasonic vibration.");
    set_mass(50);
    set_value(100);
    set_wc(5);
    set_type("blade");
    set_property("sdc_weapon", 0);
    set_property("mdc_weapon", 1);
    set_property("damage_num", 2);
    set_property("damage_sides", 6);
    set_property("damage_string", "2d6");
}

Armor: same pattern with create armor and properties ac, ar, sdc, mdc, slot.

Spawn / clone

add bandit to here

Appends a guarded reset() spawn. Refuses if the room already has reset() (hand-edit then).

void reset() {
 ::reset();
 if(!present("bandit", this_object()))
  clone_object("/realms/coder/area/npc/bandit")->move(this_object());
}
clone vibro_knife
QCS: cloned /realms/coder/area/weap/vibro_knife.c to your inventory.

Tips

  • Short lowercase filenames with underscores; QCS sanitizes them
  • create room links exits both ways in your realm
  • Spawn NPCs from reset() with present() guards
  • Test with clone before promoting into /domains/
  • Generated files are plain LPC; polish with ed, then update
