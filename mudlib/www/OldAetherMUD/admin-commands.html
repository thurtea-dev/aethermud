Admin Command Reference

  • Position: arch / head arch only.
  • Paths: cmds/adm, secure/cmds/adm, cmds/creator, secure/cmds/creator - added only when position is exactly arch or head arch.
  • Coding wizards (creator/immortal) do not get these directories; see Coding.

cmds/adm

Player and character

CommandWhat it does
advanceForce-advance N levels; reroll HP/SDC/PPE/ISP gains.
giveClone path object to online player.
grantrace / grantskillsBackfill race spells/psionics or class skills.
repaircharDiagnose/repair: dump chargen flags; clear/finish stuck creation; reroll attributes; skills re-grant package; setstat. Online only. Not a substitute for setocc/setrcc.
fixdemoteOffline demotion repair on a named save.
severNarrative limb sever/restore: sever <player> <limb>, ... restore <limb>, or ... list. No combat damage.
makecharmakechar <player> <race> <occ|none> <alignment> plus optional zone=, gear=, skills=, spells=, psi=.
setfactionSet/clear faction.
setocc / setrccSet class, or set race and re-roll race stats.
setroleWizard position/role: admin, domain, coding, rp.
setskillSet Rifts skill %.
statFull stat dump (online).
makewizPromote online mortal to Apprentice.
playerwipeWipe save, postal data, realm directory.

CommandWhat it does

Communication

CommandWhat it does

Logging and diagnostics

CommandWhat it does

Game state

CommandWhat it does
