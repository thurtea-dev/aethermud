    Horror Factor itself is unimplemented beyond a displayed
    saving-throw number (vs_hf/vs_insanity in _saving_throws.c, no code
    path reads either). Building insanities would mean building that
    trigger infrastructure first, judged not worth the scope. Addiction
    (the other half of staff-handbook/ch15-insanities.md's title) IS
    implemented (daemon/addiction_d.c) and was never in question.
    staff-handbook/ch15-insanities.md rewritten from a TODO stub to state
